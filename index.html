Both strings are 64 bits long, yet the first has a short description and the second, as far as anyone can tell, does not. Kolmogorov complexity formalizes this idea where the complexity of a string is the length of the shortest program that outputs it. We will dive into the theorems and the applications of these findings specifically to music.

Outline

  1. Introduction to Kolmogorov complexity

    Motivation from the example above, then the formal definition \(K_U(x) = \min\{|p| : U(p) = x\}\) for a fixed Turing machine \(U\). Simple bounds such as \(K(x) \le |x| + O(1)\), plus conditional complexity \(K(x \mid y)\), which later sections rely on.

  2. The invariance theorem (main theorem)

    Statement and full proof that for any two universal machines \(U, V\) there is a constant \(c\) with \(|K_U(x) - K_V(x)| \le c\) for all \(x\). Discussion of why this makes \(K\) a meaningful property of the string rather than of the programming language.

  3. Incompressible strings

    A counting argument shows that for every \(n\), at least one string of length \(n\) has \(K(x) \ge n\), and most strings are nearly incompressible. This gives a definition of what it means for a single string to be random.

  4. Uncomputability and the halting problem

    Proof that \(K\) is not computable, via a Berry-paradox argument and via a reduction connecting it to the halting problem. Also covers what we can do: \(K\) can be approximated from above, but we never know when we are done.

  5. Chaitin’s incompleteness theorem

    Any consistent, sound formal system with a computable set of axioms can prove \(K(x) > L\) for only finitely many \(x\), even though almost all strings satisfy it. Proof, and its relationship to Gödel’s incompleteness theorem.

  6. From theory to practice: compression distance

    Information distance and the normalized compression distance (NCD), which replaces the uncomputable \(K\) with the output length of a real compressor such as gzip or bzip2. What is lost in the approximation and why it still works surprisingly well.

  7. Application: clustering music

    How Cilibrasi, Vitányi and de Wolf used NCD on MIDI files to group pieces by composer and genre with no musical knowledge built in. Walkthrough of their method, results, and limitations, with a small worked example.

    Textbooks, lecture notes and papers used to build this site.
